2. PRIVACY & LOCAL DATA PROCESSING GUARANTEE
------------------------------------------------------------------------
QuickShot is designed with a strict local-first architecture:
  (a) No Telemetry or Analytics: The Software does not collect, transmit,
      or store any personal data, usage telemetry, or crash reports on
      external servers.
  (b) Local Screen Capture: All screen captures, pixel buffers, and
      annotations are processed 100% locally in your device's memory,
      system clipboard, or local filesystem (e.g. Pictures/Screenshots).
  (c) Optional External Connections: The Software makes external network
      connections ONLY in two limited circumstances:
      1. Optional SHA-512 verified update checks against GitHub Releases
         (https://github.com/treatacookie/QuickShot/releases/latest/download/latest.yml),
         which may be disabled anytime in Options -> Software Updates.
      2. When you explicitly click "Search similar images on Google" (Ctrl+G),
         which encodes that single selected region in RAM and submits it
         directly over HTTPS to Google Lens (https://lens.google.com/v3/upload)
         to open live visual search results in your browser (with automatic
         clipboard copy + https://www.google.com/?olud fallback if unreachable).
